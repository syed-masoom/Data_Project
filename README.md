# 📊 Excel Data Analytics Portfolio

Welcome to my Excel Data Analytics Project.

This repository showcases a collection of end-to-end business analytics projects built entirely in Microsoft Excel. Each project is designed around real-world business scenarios and demonstrates how Excel can be used to clean, analyze, visualize, and present data-driven insights for business decision-making.

Rather than focusing only on charts and dashboards, every project follows the complete analytics workflow—from understanding the business problem to delivering actionable recommendations.

---

# 🎯 Project Objective

The purpose of this portfolio is to demonstrate practical business analytics skills using Microsoft Excel.

Each dashboard answers real business questions such as:

- Which products generate the highest revenue and profit?
- How do sales change over time?
- Which customer segments are the most valuable?
- How effective are discounts and promotions?
- Which regions or sales channels perform best?
- How can business performance be improved using data?

Every project has been developed using realistic datasets and business scenarios similar to those encountered in retail, e-commerce, and sales analytics roles.
